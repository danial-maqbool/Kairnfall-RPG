# Kairnfall Ultimate 2D Game Sprite Pack

Original sprite pack generated locally for Kairnfall. No GitHub or third-party artwork is required.

Actor sheets use 64x64 frames in an 8x24 grid (512x1536): idle, walk, attack, cast, hit, death; south, west, east, north; 8 frames per direction. Foot contact is y=55. Boss sheets use the same grid with 128x128 frames.

This pack contains 1066 game assets plus previews and metadata.
