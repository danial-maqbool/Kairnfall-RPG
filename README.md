# Kairnfall

Persistent top-down medieval fantasy RPG for Windows.

## Build status

Implementation is in progress. This repository is not a completed MMORPG release.
The accepted specification requires Godot 4.7.2 .NET, a .NET 10 authoritative server,
PostgreSQL persistence, eight classes, 60 trainable skills, and five connected cities.
Content counts are acceptance targets, not claims about implemented content.

## Art requirement

Use detailed pixel-art sprites based on the structure of real objects.
Weapons must show a blade or head, handle, guard, and material changes where applicable.
Buildings must show construction details. Animals must show identifiable anatomy.
Do not use flat single-colour shapes as final game assets.

## Verification policy

Track implemented, tested, and incomplete work separately.
Never claim a test passed without its recorded result.
Never claim independent agents ran unless a worker runtime actually executed them.
Never describe generated content records as finished gameplay without integration tests.

Original source code will use the MIT license. Third-party art retains its own license.
